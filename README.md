# Eastside - inventario (copia temporanea)

Copia pubblicata su GitHub Pages della sola pagina `inventario.html` del gestionale Eastside.
Non modificare qui: i file sono generati dal repository del progetto con
`npm run inventario:pubblica` e vanno aggiornati da li.

Serve a usare l'inventario finche il gestionale non e completo; poi la pagina vive nel gestionale
(`/gestionale/inventario.html`) e questa copia va dismessa.

La pagina richiede un account: senza accesso non mostra dati.
